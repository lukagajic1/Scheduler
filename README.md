# Scheduler

Scheduler is a full-stack appointment-management application for small service businesses. It allows authenticated users to manage clients, schedule appointments, and view bookings by date.

## Features

* Session-based authentication
* Client creation, editing, and deletion
* Appointment creation, editing, and deletion
* Searchable client selection
* Date-based schedule filtering
* Appointment conflict prevention

## Technologies

* React
* Tailwind CSS
* Node.js and Express
* PostgreSQL
* Neon, Render, and Vercel
